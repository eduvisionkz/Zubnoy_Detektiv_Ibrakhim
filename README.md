# Зубной детектив

Интерактивная лаборатория по исследовательской работе «Кислотность напитков и их влияние на зубы».
Автор: Сагидолда Ибрахим, 4 «Б» класс. Руководитель: Токашова С. Заманбековна.
КГУ «Средняя школа имени Шокана Уалиханова», село Тугыл, 2026.

Сайт — один файл `index.html`. Работает без интернета, без сервера и без установки.

- С флешки: откройте `Zubnoy_Detektiv_Ibrakhim.html` двойным щелчком (Chrome или Edge).
- Режим защиты сразу: добавьте к адресу `#defense` (например, `.../index.html#defense`).
- Памятка: `#smile`.

## GitHub Pages
1. Создайте репозиторий на github.com (например, `zubnoy-detektiv`), публичный.
2. Add file → Upload files → перетащите `index.html`, `.nojekyll`, `README.md` → Commit.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/zubnoy-detektiv/`.

## Vercel
1. Войдите на vercel.com (можно через GitHub).
2. Add New → Project → Import репозитория из шага выше → Framework Preset: «Other» → Deploy.
   Сборка не нужна: Vercel отдаёт `index.html` как статический сайт.
3. Обновление: загрузите новый `index.html` в репозиторий — Vercel и GitHub Pages обновятся сами.
